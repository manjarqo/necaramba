# Матрица приёмки независимого аналога для macOS

Дата: 2026-10-14. Платформа: Swift/AppKit, macOS 12+, Universal 2 (`arm64`, `x86_64`). Это **test oracle будущего продукта**, не протокол испытаний Caramba и не план реализации.

Все строки имеют статус **D / design target, не выполнено**; пометка **release gate** означает обязательную проверку/решение перед заявлением совместимости. Runtime-подтверждения для этой матрицы не предоставлены. Ни одна строка не означает, что Caramba демонстрирует именно это поведение. Точное равенство закрытой языковой модели не является критерием: проверяются независимые правила, явно зафиксированные fixtures и согласованная совместимость пользовательских сценариев.

## Общие условия и fixtures

- Начальное поле пустое, editable, с кареткой в конце, без selection, собственного autocorrect и IME composition; если строка не устанавливает иное. Рабочие adapter/application combinations должны быть перечислены в release compatibility manifest.
- `M-test` — независимый тестовый snapshot правил. В нём `ghbdtn→привет` и `руддщ→hello` являются высокоуверенными layout cases; исправления `превет→привет`, `teh→the`; `ПРивет→Привет`; ё-правило `елка→ёлка`. `все`, `узнаем`, `API`, `abc123`, URL, email и пути без контекста не исправляются. Эти пары — заданные test fixtures, не извлечённые правила Caramba.
- Для тестов layout/typo решающей границей является пробел. Пробел остаётся ровно один. Раннее исправление во время слова допустимо только как отдельно согласованный вариант; итог и сохранность событий обязательны.
- `G-test` — профиль жестов: одиночный незакомбинованный Shift переключает источник после окна ожидания 300 мс; две отдельные пары down/up одного либо разных Shift в пределах 300 мс вызывают manual action: надёжно полученное выделение → его конвертация; иначе валидная собственная undo transaction → undo; иначе текущее слово → convert. Одиночное переключение подавляется. Одновременные Left+Right Shift — отдельный SplitShift при включённой опции. Порог проектный; соответствие таймингу эталона — release gate.
- `H-test` — команды из спецификации: DoubleShift вызывает manual action, одиночная незакомбинованная Option — ту же action только при включённой опции; Cmd+Shift+V — plain paste при включённой опции; одновременные Left+Right Shift — toggle auto при включённом SplitShift. Произвольный global shortcut recorder и отдельная global uppercase command не входят в scope.
- `W-test` — словесное исключение `превет`, app rule по bundle ID `com.example.TestEditor`, версия правила `v2`. Политика: explicit app off выше global auto; word exception блокирует auto layout/typo/ё этого слова; ручная команда разрешена при безопасном контексте независимо от auto app rule. Правило исключения не меняет другие слова.
- Любая операция, потребовавшая удаления текста, должна иметь подтверждённую цель и ограниченный размер. При неопределённости ожидается отказ до разрушительного шага. Незавершённая операция не должна самостоятельно повторяться в другом поле.
- Реальные пользовательские данные, пароли и личный clipboard для испытаний не нужны: только synthetic fixtures. System Settings права переключает тестовый оператор в отдельной тестовой среде.

## Правило отчётности

Для каждой выполненной строки сохранять: build SHA, architecture/OS, adapter/application version, модель/fixture hash, начальные права и input source, фактический результат, capture или воспроизводимый log без личного текста. `Passed` допустим только после выполнения; unsupported surface отражается отдельной строкой compatibility manifest. Измеренный результат эталона и результат будущего аналога хранить раздельно. Изменение oracle требует объяснения продуктового решения, а не подгонки под неудавшуюся реализацию.
