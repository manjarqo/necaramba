# Наблюдение живого интерфейса Caramba Switcher Pro

Дата: 2026-10-14. Объект: `/Applications/Caramba Switcher Pro.app`. Метод: CUA `getApp`, accessibility tree и снимки целевого окна. Версия, показанная интерфейсом: **2026.09.22**. Это runtime-наблюдение интерфейса, а не доказательство корректности преобразования текста.

## Подтверждённые экраны и возможности

| ID | Наблюдение | Доказательство и предел |
|---|---|---|
| UI-01 | Главное окно содержит Автопереключение, Опечатки, Ёфикатор, Single Shift, Звук | Текст и изображения плиток в AX; визуально пять крупных плиток |
| UI-02 | Double Shift или Option предназначены для переключения слова либо выделения | Прямой текст окна; срабатывание не тестировалось |
| UI-03 | Option можно отдельно включить для переключения набранного слова или выделения | Отдельный checkbox |
| UI-04 | Single Shift меняет раскладку клавиатуры | Прямой текст окна |
| UI-05 | Left Shift + Right Shift включает/выключает автопереключение | Отдельный checkbox |
| UI-06 | Command + Shift + V вставляет текст без форматирования | Отдельный checkbox |
| UI-07 | Исключения открывают sheet «Правила автопереключения» | Две вкладки «Для слов» и «В программах» |
| UI-08 | Вкладка исключений слов содержит таблицу и +/− | Подпись «Caramba не будет исправлять эти слова»; операции не выполнялись |

| UI-10 | Экран лицензии содержит состояние поддержки/активации, следующее автопродление, управление подписками и восстановление покупок | Только просмотр; переходов к управлению/восстановлению не было |
| UI-11 | О программе содержит версию, описание, ссылки на соглашение, конфиденциальность, сайт и обратную связь | Только просмотр; ссылки не открывались |
| UI-12 | Главное окно содержит кнопку версии и кнопку «Ещё программы Caramba Lab» | Кнопки не нажимались; их точное действие не установлено |
| UI-13 | Меню приложения содержит О программе и Выход, File содержит Close/Закрыть все | Меню прочитаны, команды не выполнялись |

## Текущее состояние профиля — не значения по умолчанию

- Checkbox Option: `0` (выключен).
- Checkbox Left Shift + Right Shift: `0` (выключен).
- Checkbox Command + Shift + V: `1` (включён).
- Визуально плитки Автопереключение и Опечатки серые; Ёфикатор, Single Shift и Звук зелёные. Accessibility tree предоставляет их как изображения и не сообщает булево состояние. Интерпретация цвета как включено/выключено вероятна, но не подтверждена переключением.
- Возле первых четырёх плиток видны «5 час.», «10 мин.», «41 мин.», «15 час.». UI не поясняет единицу учёта или способ расчёта, поэтому нельзя выдавать это за измеренную экономию времени.
- Обе таблицы исключений визуально пусты в текущем профиле.
- Экран лицензии показывает действующую подписку и дату следующего автопродления. Точная дата намеренно не включена в исследовательские файлы как ненужное для функциональной спецификации состояние аккаунта.

## Стандартное меню Edit

Наблюдались Undo/Redo, Cut/Copy/Paste/Paste and Match Style/Delete/Select All, Find, Spelling and Grammar, Substitutions, Transformations, Speech, Autofill, Dictation, Emoji and Symbols. Большинство пунктов отключено вне редактируемого поля. Эти стандартные AppKit-команды **не доказывают собственные возможности Caramba** (в частности, smart quotes, регистр, диктовку, автозаполнение паролей или преобразование текста в других приложениях).

## Ограничения и необходимые последующие проверки

Параметры и пользовательские данные не менялись; ввод тестового текста, работа с pasteboard, перехватом событий, Accessibility API другого приложения и глобальными сочетаниями не проводились. TCC не изменялся. Плитки не нажимались. Диалоги добавления/удаления исключений не открывались, поскольку неизвестно, создаёт ли кнопка запись немедленно. Status bar menu не исследовано: доступное AX-дерево целевого окна содержит только обычную полосу меню.

Из данного этапа нельзя установить языковые пары, алгоритм распознавания/переключения, тайминги Double Shift, границы слова, механизм отмены, обработку выделения, поведение Secure Input, поддержку конкретных редакторов/браузеров, старт при входе, многомониторность, механизм обновления или требования к разрешениям. Их необходимо сопоставить со статическим анализом и проверить в отдельном тестовом профиле на синтетических строках.

После исследования закрыты sheet и раскрытые меню, оставлено главное окно. Последнее AX-наблюдение подтвердило прежние значения трёх checkbox.

Сокращённые исходные наблюдения: [runtime-ax-observations.txt](evidence/runtime-ax-observations.txt). Изображения были просмотрены в tool output; отдельные PNG-файлы не сохранялись.
