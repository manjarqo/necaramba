# Исследование Caramba Switcher Pro для проекта Necaramba

## Дополнение 2026-10-15

Повторная проверка установленного артефакта совпала с сохранёнными хэшами ресурсов. [Углублённый разбор модели](model-followup-2026-10-15.md) восстановил CLM1 → ChaCha20 → zstd → protobuf и полный локальный экспорт графов/таблиц: 165913 классификационных шаблонов, 72595 правил автокоррекции и 486 шаблонов Appex. Все ссылки графов разрешаются; wire-export побайтово восстанавливает plaintext. Данные остаются в игнорируемых локальных research artifacts, а не в распространяемом продукте.

[Поведенческий разбор](behavior-followup-2026-10-15.md) уточняет границы слова, replay, классификацию и обработку правил. Это статические доказательства; они не означают, что весь алгоритм уже перенесён в Necaramba или физическое соответствие проверено. Сведения ниже о нерасшифрованном payload описывают состояние на 2026-10-14 и уточняются дополнением. Подпись модели отдельно не проверялась, происхождение словарных данных не установлено.

Исследована установленная macOS-сборка **2026.09.22 (20260922.2)**, bundle `tech.caramba.switcher`. Дата отчёта: 2026-10-14. Выполнены inventory/подпись/ресурсы, просмотр живого UI, полная пакетная декомпиляция обнаруженных локальных non-thunk функций arm64 трёх собственных Mach-O и углублённый разбор основных механизмов. Подготовлены независимая спецификация и план Flutter UI + Swift native core, macOS12+, arm64/x86_64.

**Не доказаны:** полное семантическое понимание каждой функции, точное совпадение языковой модели и все сценарии физического ввода. Исходный Swift/Rust проект не восстановлен. x86_64 отдельно не декомпилирован; backend не исследован изнутри. Это существенные границы результата, а не пройденные тесты.

## Главные результаты

Основной UI написан с использованием Swift, языковое/event ядро содержит Rust. Перехват идёт через CGEvent tap с Secure Input и permission checks; TIS/UCKeyTranslate связывают источники ввода и физические клавиши. Замены используют layout activation/readback, bounded retries, backspaces и retyping, включая оптимизацию общего префикса. Существуют глобальная и PID-адресованная отправка событий.

Подтверждены автоисправления RU/EN, опечатки, двойные заглавные и ё; Shift/Option команды, plain paste, исключения слов/приложений, обновления правил, звук и импорт звука, 25 цветов и drag/drop картинки шапки, статистика, permissions/onboarding, login item, справка/диагностика, trial/subscription/restore и интерфейс RU/EN. Сила доказательства различается по функции; точные контракты отмечены в документах. Автоматическое обучение исключениям удалено в changelog2026.09.20, хотя старые рекламные описания его упоминают.

Есть Core Data модели версий1–8 и CLM1 языковой ресурс. Наличие CloudKit entitlement не доказывает работающую синхронизацию: найденный store setup отключает CloudKit options. CLM1 содержит проверяемый header, подписанный payload и cipher pipeline; словарь/веса целиком не восстановлены. Серверные URL/headers и Sentry строки не доказывают передачу конкретных данных.

Новый продукт проектируется с Flutter UI и локальным Swift-ядром и независимо созданными правилами. Возможность MAS-релиза проверяется отдельно от Developer ID: наличие sandbox у оригинала не доказывает пригодность нового event/AX решения для MAS.
