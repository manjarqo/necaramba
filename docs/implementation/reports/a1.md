- InputTypes: LayoutID (RawRepresentable/Codable/Hashable/Sendable), Language, Modifier, EventKind, EventOrigin, InvalidationReason, ContextToken (Codable/Equatable/Sendable), InputEvent (Equatable/Sendable).

Every public struct has an explicit public initializer. Core source has no imports or platform dependencies. Tests use the public module import, checking externally accessible initializers. Fixtures directory contains only a synthetic-fixture policy README; no real input or third-party assets.
