# A7 independent corpus and quality gate

Status: runner/validation and independently licensed lexical baseline implemented. **Release quality gate fails.** No shipping enablement is justified.

The raw unsigned snapshot is `Resources/Rules/independent-v1.json`, SHA256 `c5b8ffaae684f053cb57203bc364115fec413224f659d0bbac8b9b2d1b04a133`, 12,376,802 bytes, 179,000 English/Russian base words, four own typo rules, three own ё rules, uniform frequency band 1, and corpus `US`/`RU` keyboard aliases. It is independent of Caramba and is not a production signed package. Distribution must include `Resources/Rules/Licenses/`. Own synthetic transformations are CC0. These are licensed, dictionary-derived single-word oracles, **not a natural typing gold standard**, editor acceptance corpus, or empirical language-frequency sample. Affixes are not expanded. No personal text, installed-app resources, CLM1, or recovered implementation is included.

Current corpus revision is `independent-v2-oracle-fix`, 18,010 cases: train 6,002; calibration 6,002; holdout 6,006; holdout no-change 3,602. Coarse first-four-character families (language-specific, ё folded for grouping) stay in one split. Unicode-normalized identical input/expected values also cannot cross splits. The full external dictionary is fixed prior lexical knowledge, not trained from these evaluation labels. Prefix grouping does not prove complete linguistic/morphological independence. The synthetic cases cover lower/title/upper case, both languages, wrong layout, mixed/code/URL/email/path/number guards, and keyboard punctuation. App categories are token simulations only.

## Review round 1: mandatory coverage and physical evidence

New commit follows the original A7 baseline without changing the signed-candidate raw model, original v1/v2 corpus files, or historical `Reports/quality.json` / `Reports/calibration.json`. New artifacts live in `Corpora/ReviewV3/` and `Reports/review-v3-{quality,calibration}.json`. Raw model SHA remains `c5b8ffaae684f053cb57203bc364115fec413224f659d0bbac8b9b2d1b04a133`.

`QualityEvaluator.passed` now requires both token metrics plus independent-family coverage and an explicit separately supplied `physicalDifferentialQualified` flag. That flag defaults false. The token-only CLI cannot set it true and always reports physical differential UNRUN; perfect token predictions cannot yield release-quality exit 0. `tokenQualityPassed` is exposed separately. No permission, UI, TCC, installed-app, or physical-device action was taken. A trusted future integration must supply physical qualification from actual reviewed differential evidence; synthetic scenario metadata never qualifies it.

Fixed mandatory coverage floors (review design parameters, not recovered constants or statistical population guarantees): layout 100 independent families, typo 10, ё 10, doubleCaps 20; each English/Russian language 100; lowercase/title/uppercase/mixed case 100 each and doubleCaps case 20; each editor/browser/terminal/office/chat application category 100. The report publishes sample count, distinct normalized family count, required count and pass/fail for every stratum. Repeating case variants of one family counts once. Missing strata fail even with perfect overall metrics and sizes. Per-stratum confusion counts remain separate from coverage counts.

Schema 2 cases declare `language`, `caseShape`, `applicationCategory`, and `hostScenarioID`. Hosts are exactly `synthetic.<application>.token-only`; native bundle IDs are rejected as synthetic metadata. The runner varies the synthetic ContextToken bundle identifier to preserve the declared category, but still evaluates only lexical tokens with no physical events or host interaction. Categories are **representative token labels**, not acceptance claims about TextEdit, browsers, terminals, Office, or chat apps. Schema 1 historical corpora remain readable but cannot satisfy metadata coverage gates. Schema 2 requires complete metadata, validates actual source case shape, and pins generation assets in addition to original source/lexical/license inputs.

Reviewed v3 contains 25,259 examples (train 8,400; calibration 8,400; holdout 8,459). It is a coverage revision of the original synthetic dictionary corpus, **not an unseen independent natural-typing test set**. Old predictions were not used to select favorable examples, change rules, or tune parameters. The independently authored challenge definitions were frozen before new predictions.
