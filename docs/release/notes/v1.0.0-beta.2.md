## English

**Necaramba 1.0.0 Beta 2** — a free, open-source keyboard-layout switcher for Mac.

### Changes since Beta 1

- **Choose your layout-switching shortcut:** Shift, Alt (Option) + Shift, Ctrl + Shift, **Command + Shift**, or Off.
- **Refined shortcut settings:** compact selection menu, current-choice checkmark, keyboard symbols, English/Russian labels, and support for narrow windows and larger text.
- **Reliable chord handling:** either left/right modifier and either press/release order work. The layout changes once after all keys are released; typing another key cancels the action. Commands such as **⌘⇧V** do not also switch the layout.
- **Double Shift remains available** for converting the last word or selected text, regardless of the layout-switching choice. Option-based manual correction and left/right Shift control retain their separate behavior.
- **Persistent settings and migration:** existing Shift on/off preferences are preserved. The selected shortcut survives restart, settings export/import and changes to automatic-correction settings.

### Download and install

Download **Necaramba-1.0.0-beta.2-macos-universal.zip**, extract it, quit the previous copy, and move **Necaramba.app** to **Applications**. Choose your shortcut in **Settings → Keyboard shortcuts → Switch input language**.

Requires **macOS 12+**, Apple Silicon or Intel. Universal arm64/x86_64 binaries; actual Intel/macOS 12 execution remains unqualified. App bundle version: **1.0.0 (2)**; source package version: **1.0.0-beta.2+2**.

This is a **pre-release**, signed with Apple Development and **not notarized**. macOS may block first launch. If you choose to run it, use System Settings → Privacy & Security → Open Anyway after attempting to open it; managed Macs may prohibit this. Grant Accessibility and Input Monitoring, then refresh permission status in the app or relaunch if requested. This optimized build still uses the development rule package, not a qualified production distribution.

Validation: **305 Swift tests, 62 Flutter tests**, and clean Flutter analysis. The gesture tests cover Command/Control/Option variants, cancellation, persistence and migration. Physical hardware verification of the new chords is separate from automated tests. See attached **BUILD-INFO.txt** and **SHA256SUMS.txt**. Existing conservative automatic-correction and editor-compatibility limitations remain described in the README. License: **GPL-3.0-only**; source code is available at this release tag.

## Русский

**Necaramba 1.0.0 Beta 2** — бесплатный переключатель раскладки для Mac с открытым исходным кодом.

### Изменения относительно Beta 1

- **Выбор сочетания для смены раскладки:** Shift, Alt (Option) + Shift, Ctrl + Shift, **Command + Shift** или Выключено.
- **Обновлённая настройка сочетаний:** компактное меню, отметка текущего выбора, символы клавиш, русский/английский интерфейс и адаптация к узкому окну и увеличенному тексту.
- **Обработка комбинаций:** поддерживаются левые/правые клавиши и любой порядок нажатия и отпускания. Раскладка переключается один раз после отпускания всех клавиш; нажатие другой клавиши отменяет переключение. Команды вроде **⌘⇧V** не вызывают дополнительной смены раскладки.
- **Двойной Shift продолжает работать** для преобразования последнего слова или выделенного текста независимо от выбранного сочетания. Ручное исправление через Option и управление автоматикой левым/правым Shift сохраняют свои отдельные действия.
- **Сохранение и перенос настроек:** прежнее включённое/выключенное переключение по Shift переносится автоматически. Выбор сохраняется после перезапуска, экспорта/импорта настроек и изменения автоматической коррекции.

### Скачивание и установка

Скачайте **Necaramba-1.0.0-beta.2-macos-universal.zip**, распакуйте, завершите предыдущую копию и перенесите **Necaramba.app** в **Программы**. Сочетание выбирается в **Настройки → Сочетания клавиш → Смена языка ввода**.

Требуются **macOS 12+**, Apple Silicon или Intel. Бинарники универсальные arm64/x86_64; реальная работа на Intel/macOS 12 ещё не проверена. Версия внутри приложения: **1.0.0 (2)**; версия пакета исходников: **1.0.0-beta.2+2**.

Это **предварительный выпуск**, подписанный Apple Development, **без notarization Apple**. macOS может заблокировать первый запуск. Разрешите Универсальный доступ и Мониторинг ввода, затем обновите статус разрешений или перезапустите приложение по запросу macOS.
