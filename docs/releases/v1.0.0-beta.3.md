## English

**Necaramba 1.0.0 Beta 3 — Open Model 2 and input performance**

A free, GPL-3.0-only alternative to Caramba Switcher and Punto Switcher for Mac.

### Added and improved

- **Independent open RU/EN model included in this release:** 77,892 English and 1,419,808 Russian word forms, with source provenance, licenses and reproducible generators. No proprietary dictionary or extracted model is bundled.
- **233 explicit typo corrections and 67 optional preferred ё spellings**, controlled by the additional-corrections settings. Known words and ambiguous interpretations are handled conservatively; this is not exhaustive typo coverage.
- **More responsive input processing:** asynchronous replacement verification and layout-switch waits, reusable exclusion policies and layout tables, focus-refresh coalescing, and one-shot timers instead of continuous idle polling. Existing focus and secure-input safeguards remain in place.
- **Compatibility fixes:** Spark accessibility activation and word-boundary handling, recovery after unavailable focus, Zen accessibility activation, and manual conversion of version-like text such as `1ю3ю166` → `1.3.166`.
- **Repeated double Shift:** focus reconciliation preserves repeated conversions when the app changes the layout itself. Last-word and selected-text conversion remain available.
- **Opt-in performance diagnostics:** bounded aggregate measurements without typed text, with detailed tracing disabled by default.

### Validation and limitations

455 Swift tests executed with zero failures and one optional private-model test skipped; 65 Flutter tests passed; Flutter analyze clean. The frozen synthetic holdout contains 6,006 cases: 2,383 correct layout corrections, 21 missed corrections, 3,602 correctly unchanged cases and zero false corrections. These figures do not establish universal editor compatibility or complete dictionary coverage. No end-to-end speedup percentage is claimed.

### Install

Download **Necaramba-1.0.0-beta.3-macos-universal.zip**, extract it, quit the previous copy and move **Necaramba.app** to **Applications**. Requires macOS 12+, Apple Silicon or Intel; binaries contain both architectures. Actual Intel/macOS 12 runtime qualification remains outstanding.

App bundle version: **1.0.0 (3)**. Source version: **1.0.0-beta.3+3**. This is a **pre-release**, signed with Apple Development and **not notarized**; it includes development fallback rules and is not a qualified production artifact. macOS may block first launch. If you choose to proceed, use System Settings → Privacy & Security → Open Anyway after attempting to open it. Allow Accessibility and Input Monitoring when requested; refresh permission status or restart as macOS requires.

Source builds: set `NECARAMBA_OPEN_MODEL=YES` and leave `NECARAMBA_LOCAL_PATTERN_MODEL` unset. See **BUILD-INFO.txt** and **SHA256SUMS.txt** for artifact details and checksums. Third-party dictionary notices are included alongside GPL-3.0-only application sources.

## Русский

**Necaramba 1.0.0 Beta 3 — открытая модель 2 и оптимизация ввода**

Бесплатная альтернатива Caramba Switcher и Punto Switcher для Mac с открытым исходным кодом под GPL-3.0-only.

### Что добавлено и улучшено

- **В выпуск включена независимая открытая RU/EN-модель:** 77 892 английские и 1 419 808 русских словоформ. Опубликованы источники, лицензии и генераторы для воспроизводимой сборки. Проприетарные словари и извлечённая закрытая модель в комплект не входят.
- **233 явных исправления опечаток и 67 опциональных вариантов написания с «ё»**, управляемых в настройках дополнительных исправлений. Известные слова и неоднозначные варианты обрабатываются консервативно; покрытие опечаток не является исчерпывающим.
- **Оптимизирована обработка ввода:** асинхронные ожидания проверки замены и смены раскладки, повторное использование правил исключений и таблиц раскладок, объединение проверок фокуса и таймеры по необходимости. Проверки фокуса и защищённого ввода сохранены.
- **Улучшена совместимость:** активация доступности Spark и обработка границ слов, восстановление после временной потери фокуса, активация доступности Zen и ручное преобразование версий вида `1ю3ю166` → `1.3.166`.
- **Повторный двойной Shift:** собственная смена раскладки больше не сбрасывает контекст того же поля. Сохранены преобразование последнего слова и выделенного текста.
- **Диагностика производительности по запросу:** ограниченные агрегированные метрики без вводимого текста; подробная трассировка по умолчанию отключена.

### Проверки и ограничения

Выполнено 455 Swift-тестов без ошибок, один опциональный тест закрытой модели пропущен; прошли 65 Flutter-тестов, Flutter analyze без замечаний. В замороженной синтетической выборке из 6006 случаев: 2383 верных исправления раскладки, 21 пропущенное исправление, 3602 верно оставленных без изменения случая и ни одного ложного исправления. Это не гарантирует совместимость со всеми редакторами или полноту словаря. Процент ускорения приложения целиком пока не заявляется.
