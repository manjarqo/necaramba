## English

**Necaramba 1.0.0 Beta 6 — Fedora / GNOME**

Necaramba now runs on Fedora as a GNOME Shell extension. The macOS app is unchanged since Beta 5.

### Added

- **GNOME Shell extension for Fedora 45 (GNOME Shell 51, Wayland).** No root access, no `input` group and no system configuration changes.
- **Layout switching on release:** Shift (default), Alt+Shift, Ctrl+Shift or Super+Shift. Like on macOS, the shortcut fires once after the keys are released, and only if nothing was typed while they were held. Shift+letter still types a capital letter. If a native XKB toggle already uses the same keys, Necaramba stays inactive for that shortcut and the settings page shows a warning.
- **Double Shift converts the last word or the selection** between `us` and `ru` (`ghbdtn` → `привет`, `руддщ` → `hello`). The target layout is selected afterwards, and double Shift again converts back. The method is chosen automatically:
  - **Surrounding text** in GTK 3/4, Qt and Firefox. Works after moving the caret with the mouse; password fields are skipped.
  - **Retype** in terminals, XWayland and Chromium/Electron apps: the physical keys of the word are erased and typed again in the other layout. No clipboard is used.
  - **Selection** in apps that do not report surrounding text: the selected text is read from PRIMARY only if the selection changed after your last key press or click, then retyped over the selection. Not used in terminals.
  - **Chromium/Electron with Wayland IME** (for example the VSCodium flatpak): the field's last surrounding text is kept after the first Shift tap resets the input method.
- **Settings page** with the shortcut choice and a double-Shift switch, in English and Russian.
- **Journal diagnostics:** one line per double Shift with the method and the result, never the text (`journalctl --user -b -g necaramba`).

### Validation and limitations

94 unit tests and 53 end-to-end checks passed in a headless GNOME Shell 51 session. The end-to-end clients were GTK4, a VTE terminal, GTK3 through XWayland and GTK3 on Wayland without an input method. On a real Fedora session the project owner confirmed layout switching and double Shift in regular GTK apps, and reported last-word conversion working in Electron apps. Terminals and selected-text conversion in Electron have not been confirmed on a real session yet. Not covered: GNOME versions other than 51, X11 sessions, IBus engines other than plain XKB layouts, and layout pairs other than `us`/`ru`. Retype cannot tell whether an XWayland/Electron field is a password field. Editors that insert text themselves can make the erase count wrong. Automatic correction remains macOS-only.

### Install

Download **necaramba@local.necaramba.app.shell-extension.zip** and run:

```bash
gnome-extensions install --force necaramba@local.necaramba.app.shell-extension.zip
```

Log out and back in, then run `gnome-extensions enable necaramba@local.necaramba.app`. Choose the shortcut in *Extensions → Necaramba → Settings*. See **SHA256SUMS.txt** for checksums.

Source version: **1.0.0-beta.6+6**. This is a **pre-release**. The extension is not published on extensions.gnome.org.

## Русский

**Necaramba 1.0.0 Beta 6 — Fedora / GNOME**

Necaramba теперь работает на Fedora как расширение GNOME Shell. Приложение для macOS с Beta 5 не менялось.

### Что добавлено

- **Расширение GNOME Shell для Fedora 45 (GNOME Shell 51, Wayland).** Не нужны root-права, группа `input` или изменения системных настроек.
- **Переключение раскладки по отпусканию:** Shift (по умолчанию), Alt+Shift, Ctrl+Shift или Super+Shift. Как в macOS, сочетание срабатывает один раз после отпускания клавиш и только если, пока они были нажаты, ничего не набиралось. Shift+буква по-прежнему печатает заглавную. Если штатная опция XKB уже переключает раскладку этими же клавишами, Necaramba для этого сочетания не включается, а в настройках показывается предупреждение.
- **Двойной Shift конвертирует последнее слово или выделение** между `us` и `ru` (`ghbdtn` → `привет`, `руддщ` → `hello`). После этого включается нужная раскладка, а повторный двойной Shift возвращает текст обратно. Способ выбирается автоматически:
  - **По тексту вокруг курсора** в GTK 3/4, Qt и Firefox. Работает и после перемещения курсора мышью; поля паролей пропускаются.
  - **Перенабором** в терминалах, XWayland и Chromium/Electron: клавиши слова стираются и набираются заново в другой раскладке. Буфер обмена не используется.
  - **По выделению** в приложениях, которые не сообщают текст вокруг курсора. Выделенный текст берётся из PRIMARY, только если выделение изменилось после последнего нажатия клавиши или клика, и набирается поверх выделения. В терминалах не используется.
  - **Chromium/Electron с Wayland IME** (например, flatpak VSCodium): последний текст поля сохраняется, когда первый тап Shift сбрасывает метод ввода.
- **Страница настроек** с выбором сочетания и переключателем двойного Shift, на английском и русском.
- **Диагностика в журнале:** одна строка на каждый двойной Shift со способом и результатом, без самого текста (`journalctl --user -b -g necaramba`).

### Проверки и ограничения

Прошли 94 юнит-теста и 53 сквозные проверки в headless-сеансе GNOME Shell 51. Сквозные проверки шли в клиентах GTK4, терминале VTE, GTK3 через XWayland и GTK3 на Wayland без метода ввода. В реальном сеансе Fedora владелец проекта подтвердил переключение раскладки и двойной Shift в обычных GTK-приложениях, а также работу конвертации последнего слова в Electron. Терминалы и конвертация выделения в Electron в реальном сеансе пока не подтверждены. Не проверялись: версии GNOME, кроме 51, сеансы X11, движки IBus, кроме обычных раскладок XKB, и пары раскладок, кроме `us`/`ru`. При перенаборе нельзя узнать, что поле в XWayland/Electron — поле пароля. Редакторы, которые сами вставляют текст, могут сбить число стираемых символов. Автокоррекция остаётся только в macOS-версии.

### Установка

Скачайте **necaramba@local.necaramba.app.shell-extension.zip** и выполните:

```bash
gnome-extensions install --force necaramba@local.necaramba.app.shell-extension.zip
```

Выйдите из сеанса, войдите снова и выполните `gnome-extensions enable necaramba@local.necaramba.app`. Сочетание выбирается в *Расширения → Necaramba → Настройки*. Контрольные суммы — в **SHA256SUMS.txt**.

Версия исходников: **1.0.0-beta.6+6**. Это **предварительный выпуск**; на extensions.gnome.org расширение не опубликовано.
