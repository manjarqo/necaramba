# Independent corpus v2 (oracle encoding correction)

This is a dictionary-derived, synthetically labelled token corpus, not natural typing gold data. It does not establish compatibility with other switchers or release readiness. No third-party switcher executable, model, extracted resources, accounts, user typing, personal documents, or installed-app files are inputs.

Sources are pinned LibreOffice/dictionaries revision `67032ee957631908098a72edf48dc81cac27e369`. Full original `.dic` base-word sources and notices are preserved under `Sources/`; provenance records immutable URLs and SHA256 hashes. English source is SCOWL-derived under the permissive notices in `Sources/en/README_en_US.txt`. Russian source is Alexander I. Lebedev's BSD-style license in `Sources/ru_RU/README_ru_RU.txt`, requiring modified versions be marked. The bundled snapshot is explicitly a modified selection. These source-specific notices, not LibreOffice's repository-wide license, govern these inputs. Own guards, keyboard transformations, and narrow exact rules are CC0 as stated in `LICENSE.synthetic`.

`acquire_sources.py` reacquires the pinned sources. `generate.py` deterministically produces the independent snapshot and corpus; regeneration is a reviewed corpus revision, never a way to tune to holdout outcomes. Upstream words are restricted to lowercase alphabetic base entries of 4–20 characters; Hunspell affixes are not expanded. The snapshot has 179,000 words, uniform frequencyBand=1 (an uncalibrated design parameter, not empirical frequency), four own exact typo rules and three own ё rules. Dictionary presence is a fixed external prior, not learned from calibration/holdout labels. No statistical scoring or n-gram model has been calibrated.

Each coarse lexical family is the language plus the normalized first four letters (ё folded to е for grouping). Families are deterministically hash-assigned to one split, and sampled deterministically before predictions. Case/layout/guard variants stay in that split. The validator additionally rejects duplicate IDs, normalized identical inputs or expected values crossing splits, unknown fields, invalid labels, missing licenses, mismatched hashes, counts, unsafe paths, and declared family leakage. This coarse grouping is conservative for many inflections but is not a morphological lemma analysis; semantically related words with different prefixes can remain across splits. Short challenge families are disjoint. A source/input overlap found by validation was removed before the first prediction run; no predictions were used to modify labels, rules, or holdout.

There are 18,010 examples: 6,002 train, 6,002 calibration, and 6,006 holdout. Holdout has 3,602 no-change examples. Each selected word yields lowercase correct, uppercase protected, lowercase wrong-layout, title-case wrong-layout and one URL/email/path/code/mixed/number guard. Both-language-known layout spellings are labelled abstain. Dedicated exact-rule and unsupported-typo examples are included. These app-like tokens are synthetic categories, not editor integration tests. There is no naturalistic word-frequency weighting. An externally supplied full lexicon includes holdout words as prior lexical knowledge; train/calibration/holdout separate evaluation examples and do not represent a learned-word benchmark.

Run from the repository root after integrating the executable target:

```sh
swift run CorpusRunner --manifest Corpora/manifest.json --split calibration --output Reports/calibration.json
swift run CorpusRunner --manifest Corpora/manifest.json --split holdout --output Reports/quality.json
```

Exit 0 means point-estimate corpus thresholds and sample counts pass; exit 1 means a quality threshold is failed or undefined; exit 2 means arguments or corpus/provenance validation failed. Undefined report metric denominators are JSON null; they never satisfy gates. Exact output equality is required. A wrong replacement on a change-labelled example counts as both FP and FN; a no-change FP also contributes to the no-change false-change numerator. Layout recall is computed only over `layout*` change-labelled categories; other recall is reported separately. Per-category raw confusion counts and all exact mismatches are retained. Wilson 95% intervals expose sampling uncertainty and do not certify generalization.

The current gate fails recall. Precision and no-change point estimates alone do not establish release readiness. Typo and ё samples are sparse, doubleCaps is explicitly reported with zero samples, and Russian-PC/ISO/JIS, physical events, punctuation boundary buffering, real editors, IME/composition, mixed input sequences, and device differential tests remain unrun. A future improvement must use calibration and independently version any new holdout; retain this baseline report.

V1 contained contradictory title-case source encodings for words beginning punctuation. V2 uses the actual shifted source character. Original v1 holdout/manifest/generator and measured reports are archived for audit, explicitly invalid as quality evidence. The raw rules snapshot is unchanged and no holdout-based linguistic tuning occurred. The archived generator is a source snapshot originally located at Corpora/generate.py; its paths are relative to that original location.
